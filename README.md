# pay_2_prompt

## Setup

1. Install [mise](https://mise.jdx.dev/getting-started.html).
2. Clone the repo and enter it:

   ```sh
   git clone <repo-url>
   cd pay_2_prompt
   ```

3. Install Bun and Node at the versions pinned in `mise.toml`:

   ```sh
   mise install
   ```

4. Install dependencies:

   ```sh
   bun install
   ```

## Run

Type-check the code:

```sh
bun run typecheck
```
